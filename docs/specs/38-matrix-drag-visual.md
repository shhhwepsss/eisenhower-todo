# #38 — Перетаскивание в матрице: видимый жест и захват за всю карточку

## Задача

Сделать перетаскивание на вкладке «Матрица» видимым (карточка едет за указателем)
и брать жест за всю карточку, а не только за иконку-ручку.

## Прототип

Не требуется: направление дизайна выбрано в #35, здесь исправляется поведение жеста
внутри уже принятого вида. Новых экранов, раскладок и плотностей не добавляется.

## Скоуп

**In**

- Копия карточки в `DragOverlay`, которая летит за указателем поверх зон.
- Захват жеста с любого места карточки.
- Отбор контролов: с `<select>` статуса и кнопок разбора жест не начинается.

**Out**

- `touch-action` на карточке — отдельный issue #36. Пока жест на тач-устройствах
  не работает по другой причине, и трогать её здесь нечем.
- Автопрокрутка при переносе к зоне за краем экрана. Матрица целиком влезает
  в экран на тех ширинах, где она сеткой, — проблема не наблюдается.
- Своя тень для «поднятой» карточки. Копия отличается от карточки в зоне наклоном
  и масштабом; новый цветовой токен ради этого не заводится.
- Домен, стор, хранилище. Правится только `ui/matrix` и его дети.

**Допущения**

- Ручка остаётся на карточке: она единственный фокусируемый активатор, и на ней
  держится клавиатурный путь из #35 §12.
- Копия карточки нужна именно копией, а не сдвигом исходной: `useSortable` отдаёт
  сдвиг только внутри одного `SortableContext`, а зон у нас пять и у каждой свой.

## Инварианты

- `DRAG_IS_VISIBLE`: пока жест идёт, на экране есть копия перетаскиваемой карточки,
  и её положение следует за указателем; исходная карточка остаётся на своём месте
  приглушённой.
- `WHOLE_CARD_DRAGS`: `pointerdown` на любой части карточки, кроме её контролов,
  начинает жест.
- `CONTROLS_KEEP_THEIR_PRESS`: `pointerdown` на `<select>` статуса или на кнопке
  разбора жест не начинает, и контрол срабатывает как обычно.
- `KEYBOARD_PATH_SURVIVES`: возврат задачи во «Входящие» остаётся выполнимым
  с клавиатуры (Space → стрелки → Space).
- `DROP_FOLLOWS_POINTER`: зона броска по-прежнему ищется по указателю (не регрессирует
  0b88325).

## Критерии приёмки

- [x] Given задача в квадранте, When тащу её мышью, Then копия карточки едет
      за указателем и видна поверх зон, а исходная остаётся на месте приглушённой.
- [x] Given задача в квадранте, When начинаю жест с тела карточки (не с ручки),
      Then жест начинается.
- [x] Given задача в квадранте, When нажимаю на `<select>` статуса и двигаю указатель,
      Then жест НЕ начинается.
- [x] Given задача в квадранте, When нажимаю на кнопку «Срочная» и двигаю указатель,
      Then жест НЕ начинается, а обычный клик по ней меняет квадрант.
- [x] Given задача в квадранте, When веду указатель в колонку «Входящие» и отпускаю,
      Then задача уходит во «Входящие».
- [x] Given две задачи в одном квадранте, When тащу нижнюю на верхнюю, Then порядок
      меняется (перестановка внутри зоны не сломана).
- [x] Given фокус на ручке, When Space → стрелки → Space, Then задача переезжает
      клавиатурой.
- [x] Given жест начат, When Escape, Then копия исчезает и задача остаётся на месте.
- [x] Идемпотентность: повторный `pointerup` без жеста ничего не делает — `onDragEnd`
      приходит один раз на жест, а `draggedId` сбрасывается и в `onDragCancel`.
