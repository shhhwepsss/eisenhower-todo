# Служебное — `app_meta`

Состояние: **в схеме** (`apps/api/src/db/schema.ts:11-14`, миграция
`apps/api/drizzle/0000_app_meta.sql`). Спека: `docs/specs/51-db-migrations.md`.

## Что это

Служебная таблица «ключ — значение». Заведена, чтобы у конвейера миграций была первая
миграция до появления таблиц предметной области. Сущностью домена не является.

## Колонки

| Колонка | Тип    | Пусто | Смысл    |
| ------- | ------ | ----- | -------- |
| `key`   | `text` | нет   | ключ     |
| `value` | `text` | нет   | значение |

## Ключи и ограничения

- Первичный ключ — `key`.

## Связи

Нет.

## Кто пишет, кто читает

Никто. Код таблицу не читает и не пишет: `/api/health` сверяет журнал миграций, а не
таблицы (`apps/api/src/db/schema.ts:7-9`).

## Инварианты

Нет.

## Жизненный цикл

Нет: строк в таблице нет.
